ORDEN DE DEPURACIÓN — ELECTORAL (pipeline)
  Fase 1 → RD interno    : duplicados y errores dentro del Registro Demográfico
  Fase 2 → CEE interno   : duplicados, clusters, fallecidos dentro del padrón
  Fase 3 → RD × CEE      : cruce de registros limpios — fallecidos, conflictos SSN
  Fase 4 → staging × CESCO : validación final contra Real ID federal

CESCO — TIPOS DE DOCUMENTO
  Real ID - Licencia    Conduce + identificacion federal (estrella dorada)
  Real ID - Tarjeta ID  Solo identificacion federal, NO conduce (estrella dorada)
  Ambos son Real ID. La diferencia es el privilegio de conducir.
